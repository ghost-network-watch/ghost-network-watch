The evidence behind the grades

Every grade on this site is built from individual findings. Each row in these files is one problem in one insurer's published listing, exactly as published. Every row carries the fingerprint (SHA-256 hash) of the archived file it came from and the position of the record inside it, so anyone can check our work against the archived original.

Provider details in these files are quoted from the insurer's published directory. No claim is made about the provider. Listed clinicians are often unaware of how they appear in payer directories.

Check our work, or rebuild everything

This site is produced by open-source software from public government data. The code lives at github.com/ghost-network-watch. The inputs are all public: CMS's directory-address file for every marketplace insurer, the insurers' own published directory files, the federal NPPES provider registry, and CMS's plan and service-area filings.

The pipeline runs one command per stage: fetch the files, parse them, run the checks, compute the scores, build this site. The repository's README walks through it. Running a full month costs a few hours of computer time and produces every row summarized above, including the complete sets we sample here.
