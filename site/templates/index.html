How to use this site

  1. Look up your county with the ZIP box above, or through the state map below.
  2. Compare two numbers for each plan: the mental health grade and the provider count. A grade B list with 400 providers beats a grade B list with 12.
  3. Already stuck with an unusable list? You can demand care anyway. The guide for patients shows the exact steps and words to use.

Each plan-county pair is one plan in one county. A grade summarizes how usable that plan's published mental health list is there. The checks ask whether entries have real phone numbers and addresses, recent update dates, and identifiers the federal registry recognizes. When a plan lists fewer than 10 mental health providers in a county, we skip the grade and report the small number itself.

  • On average, {{ national.avg_ooa_pct }}% of the providers listed for a plan have no listed address in or near any county that plan covers.
  • One insurer's current file carries placeholder phone number 999999999 on {{ national.worst_phone_pct }}% of its records. The same file marks {{ national.worst_phone_accepting_pct }}% of them as accepting new patients.
  • {{ "{:,}".format(national.deactivated) }} listed identifiers appear on the federal registry's deactivated list. Half were deactivated at least {{ national.deact_median_months }} months before the file was fetched.
  • {{ national.stale_files }} directory files show a newest update date more than a year before we fetched them, against CMS guidance requiring at least monthly updates.

Every number on this site traces back to specific entries in the insurer's own published file. Each one links to an archived copy of that file, with a fingerprint that proves what the file said on the day we fetched it. See how scores are computed and the downloadable evidence.
