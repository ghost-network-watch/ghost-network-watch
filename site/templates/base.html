The Directory Integrity Score measures whether an insurer's federally mandated directory file (a public data file, not a web page) holds up as published. It is computed entirely from the insurer's own published file and dated federal registry snapshots. It is not a measure of care quality or network adequacy, and it makes no claim about any individual provider.
