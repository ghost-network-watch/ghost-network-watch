The Directory Integrity Score measures whether an insurer's federally mandated machine-readable directory file is internally consistent, current, and usable as published. It is computed entirely from the insurer's own published file and dated federal registry snapshots. It is not a measure of care quality, of network adequacy, or of any individual provider.
