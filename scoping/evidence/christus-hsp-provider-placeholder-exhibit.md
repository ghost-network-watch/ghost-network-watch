# Evidence Exhibit: CHRISTUS Health Plan PY2026 machine-readable provider directory — placeholder-data audit

**Fetched:** 2026-08-21 (fresh fetch; all data below retrieved directly from the payer's public endpoint on this date)
**Index URL:** https://chppayment.christushealth.org/workfiles/json/index.json
**Primary file audited:** https://chppayment.christushealth.org/workfiles/json/HSP_PROVIDER.json

**Framing note:** All findings below describe what the payer's own published, federally mandated
machine-readable files contain. No claim is made about the real-world status of any provider or
about intent. The claim is strictly: *the published file contains the values shown.*

## 3. Sampling method

Three 10 MB HTTP Range windows of `HSP_PROVIDER.json` (108 MB total): file start (`bytes=0-`),
middle (`bytes=50000000-`), and end (`bytes=97751504-108237263`, which includes the closing `]` of
the JSON array — i.e., the file's final records). Complete JSON records were parsed from each
window: **8,203 provider records** (~29% of the file by bytes). At the observed density
(~3,835 bytes/record) the full file holds an estimated **~28,200 records**.

Key readings:

- **100% of sampled records** carry `last_updated_on: "1900-01-01"` — a date 126 years in the past,
  in a field CMS requires precisely so consumers can judge data freshness. Not one record in any of
  the three windows has a plausible update date.
- **84.6% of records are uncontactable by every published channel simultaneously**: phone
  `999999999` (9 digits, not a valid NANP number), street address `"null"`, city `"null"`, state
  `UN`, ZIP `99999`.
- The remaining ~15% have real-looking TX/LA/AR/NM addresses and phones — but still carry the
  `1900-01-01` date, so **zero records are fully clean**.
- **89.6% are simultaneously marked `"accepting"`** new patients. The file asserts a provider is
  taking new patients while publishing no usable way to reach them.
- Placeholder rates are homogeneous across head/mid/tail (83.8% / 86.0% / 84.1% placeholder phone),
  so the combined rate extrapolates to roughly **~23,900 uncontactable provider listings of ~28,200**
  in the full file.

### Behavioral / mental health slice

Using a strict specialty match (psychiatry, psychology, counselors, clinical social work,
psych/mental health, marriage & family therapy — excluding PT/OT/speech/genetic-counselor false
positives): **524 BH records in the sample, of which 500 (95.4%) have the placeholder phone
`999999999`** (and the matching null address block). The BH slice is *worse* than the file average.
